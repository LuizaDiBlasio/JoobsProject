Para colocar este projeto em funcionamento é necessário fazer o clone do repositório para um repositório local e extrair os zips que se encontram dentro da pasta M4/projeto/utils:  

Frontend (teste cliente):

JobPortalFrontend_AppSettings.zip - Contém o AppSettings.json do projeto teste cliente (frontend), basta dar replace deste ficheiro

Também é necessário ajustar o AppSettings do projeto teste cliente para que a BaseUrl aponte para o backend - Usar https://localhost:7211/

/////////////////////////////////////////////////////////////////////////////////////////////
/////////////////////////////////////////////////////////////////////////////////////////////
/////////////////////////////////////////////////////////////////////////////////////////////
Backend (JobPortal_API):

JobPortalAPI_AppSettings.zip - Contém o AppSettings.json do projeto JobPortal_API (backend), basta dar replace do mesmo ficheiro no projeto.

Alterações AppSettings JobPortal_API:

BaseUrl tem de apontar para https://localhost:5020/ (Frontend).
No campo Jwt, alterar Issuer para https://localhost:7211 e alterar Audience para https://localhost:5020
ConnectionString, alterar para localhost com os dados correspondentes

NuGet Package Manager:

Correr Update-Database para criar a base de dados localmente
